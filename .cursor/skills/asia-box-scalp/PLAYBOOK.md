# 亚盘盒子 · 一页执行卡（日内波段）

品种 `XAUUSD`｜周期 **M15 入场 / H1 方向**｜The5ers $10k Phase1  
持仓 **30 分钟–数小时**｜可扛 **$10–20** 来回｜**默认 22:30 前平，不过夜**  
每天最多 **2 笔**

这不是超短。止损要给足空间，让价格抖 $10–20 也不至于被扫出去。

---

## 1. 14:30 画盒子（北京时间）

看 **M15**，框 **08:00–14:30**：

```text
ASIA_H = 这段最高价
ASIA_L = 这段最低价
RANGE  = ASIA_H - ASIA_L
```

三区（0.25 × RANGE）：

```text
上沿做空区 = ASIA_H 往下 25%RANGE    → 只考虑 Sell
中间禁区   = 中间 50%                 → 一律不做
下沿做多区 = ASIA_L 往上 25%RANGE    → 只考虑 Buy
```

**例**：H=4416，L=4368，RANGE=48  
上沿 4404–4416｜中间 4380–4404｜下沿 4368–4380

## 2. 开盘前：能不能做 A

**禁止策略 A（跌买多 / 涨卖空）** 若任一成立：

- H1 连续 3 根大阳或大阴
- ADX(14) **> 28**
- 价格已离开盒子超过 **1.5 × RANGE**
- CPI / NFP / FOMC **前后 30 分钟**
- 已连亏 2 笔，或当日亏损到 **-$100**

ADX **< 22** 且价格还在盒子里 → 可以做 A。  
ADX 22–28 → 宁可不做。

## 4. 下单（4 条同时满足才点）

看 **M15**，不要用 M1/M5 抢第一秒。

**Buy（下沿）**

1. 价格在下沿区  
2. M15 RSI(14) **< 35**  
3. M15 **收阳**（止跌，不是猜最低点）  
4. 在 15:10–22:00 允许入场时段  

**Sell（上沿）**

1. 价格在上沿区  
2. M15 RSI **> 65**  
3. M15 **收阴**  
4. 在允许入场时段  

**顺序：先填 SL/TP → 再点 Buy/Sell。**

## 5. SL / TP / 手数（按你能扛 $10–20 来）

| 项目 | 填什么 |
|------|--------|
| SL | **$12–18**，或 **0.3×RANGE**，取接近的；推荐先用 **$15** |
| TP | **1.5R**（SL=$15 则 TP=$22.5，可填 **$20–25**），或对向中轴 |
| 手数 | `25 ÷ (SL美元 × 100)` → SL=$15 用 **0.02**；SL=$12 用 **0.02**；SL=$20 用 **0.01** |
| 时间止损 | **90 分钟** 完全没动（浮盈从未超过 +$5）→ 平 |
| 最长 | **当天 22:30 必须平**，不隔夜 |
| 浮亏 | 允许抖到接近 SL；**不要** $5 就砍（那是超短习惯） |
| 保本 | 浮盈到 **+$15** 后，SL 移到入场价 |
| 冷却 | 两笔之间隔 **30 分钟** |

**手数为什么变小：** 止损从 $3 放到 $15，同样亏 $25，手数大约从 0.08 降到 **0.02**。  
账户亏的还是约 $25，只是价格可以多抖十几刀。
