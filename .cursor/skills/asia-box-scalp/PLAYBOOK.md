## 1. 14:30 画盒子（北京时间）

看 M15/M5，框 **08:00–14:30**：

```text
ASIA_H = 这段最高价
ASIA_L = 这段最低价
RANGE  = ASIA_H - ASIA_L
```

三区（0.25 × RANGE）：

```text
上沿做空区 = ASIA_H 往下 25%RANGE    → 只考虑 Sell
中间禁区   = 中间 50%                 → 一律不做
下沿做多区 = ASIA_L 往上 25%RANGE    → 只考虑 Buy
```

**例（已用过）**：H=4416，L=4368，RANGE=48  
上沿 4404–4416｜中间 4380–4404｜下沿 4368–4380

## 2. 开盘前 30 秒：能不能做 A

**禁止策略 A（跌买多 / 涨卖空）** 若任一成立：

- H1 连续 3 根大阳或大阴

## 4. 下单（4 条同时满足才点）

**Buy（下沿）**

1. 价格在下沿区  
2. M5 RSI(14) **< 35**（看主 RSI / 蓝线）  
3. M5 **收阳**，低点不再创新低  
4. 在允许入场的时段内  

**Sell（上沿）**

1. 价格在上沿区  
2. M5 RSI **> 65**  
3. M5 **收阴**，高点不再创新高  
4. 在允许入场的时段内  

**下单顺序：先填 SL/TP → 再点 Buy/Sell。** 没止损 = 当没下过。

## 5. SL / TP / 手数（填进软件）

| 项目 | 填什么 |
|------|--------|
| SL | **$2–4**（或 0.2×RANGE，取更小）推荐 **$3** |
| TP | **$3–6** 推荐 **$5** |
| 手数 | `25 ÷ (SL美元 × 100)` → SL=$3 用 **0.08**；不确定用 **0.05** |
| 时间止损 | **15 分钟** 未到 TP → 市价平 |
| 最长持仓 | **30 分钟** 必须平 |
| 浮亏砍 | 亏到约 0.5R（约 $12）且 5 分钟没回来 → 平 |
| 冷却 | 两笔之间隔 **15 分钟** |
