# 亚盘盒子 · 一页执行卡（日内波段）

品种 `XAUUSD`｜周期 **M15 入场 / H1 方向**｜The5ers $10k Phase1  
持仓 **30 分钟–数小时**｜可扛 **$10–20** 来回｜**01:45 前平仓，睡着不留单**  
每天最多 **2 笔**（A 和 B 合计）  
默认 **SL $15 / TP $12**（约 0.8R，胜率优先）。不要改回超短 $2–4 止损。

两套一起用：
- **A 震荡**：盒子还在，上 25% 空、下 25% 多
- **B 单边**：盒子被 M15 收盘突破后，回踩突破位顺势做

这不是超短。止损给足空间，让价格抖 $10–20 也不至于被扫出去。

---

## 1. 14:30 画盒子（北京时间）

看 **M15**，框 **08:00–14:30**：

```text
ASIA_H = 这段最高价
ASIA_L = 这段最低价
RANGE  = ASIA_H - ASIA_L
```

三区（0.25 × RANGE）：

```text
上沿做空区 = ASIA_H 往下 25%RANGE    → 只考虑 Sell
中间禁区   = 中间 50%                 → 一律不做
下沿做多区 = ASIA_L 往上 25%RANGE    → 只考虑 Buy
```

**例**：H=4416，L=4368，RANGE=48  
上沿 4404–4416｜中间 4380–4404｜下沿 4368–4380

## 2. 开盘前：能不能做 A

**禁止策略 A（跌买多 / 涨卖空）** 若任一成立：

- H1 连续 3 根大阳或大阴
- ADX(14) **> 28**
- 价格已离开盒子超过 **1.5 × RANGE**
- CPI / NFP / FOMC **前后 30 分钟**
- 已连亏 2 笔，或当日亏损到 **-$100**

ADX **< 22** 且价格还在盒子里 → 可以做 A。  
ADX 22–28 → 宁可不做。

## 3. 什么时候进场（北京）

| 时段 | 做什么 |
|------|--------|
| 08:00–14:30 | 只画盒子，A 单不进 |
| **15:00–01:00** | 允许入场（伦敦 → 纽约，可收到凌晨） |
| 15:00–15:10 | 伦敦刚开，**先看 10 分钟**再进 |
| 21:00–21:10 | 纽约刚开，**先看 10 分钟**再进 |
| **01:00 后** | 不开新仓 |
| **01:45** | **无论盈亏全部平掉**（02:00 睡觉，不隔夜） |

你大约 **02:00 睡**，所以不用 22:30 收工。纽约盘正好能做完。  
01:00 后流动性变差，只平仓、不再开新单。

## 4. 怎么下单：限价为主，RSI 可选

**RSI 不是必须。** 你能扛 $10–20，更适合把单子提前挂在盒子边上，让价格来成交。

### 主做法：限价单（推荐）

14:30 盒子锁完，且不是趋势日，在 MT5 挂：

```text
Buy Limit  = ASIA_L + 约 $5（稍进盒子，更容易成交）
Sell Limit = ASIA_H - 约 $5
两张单都先填好 SL / TP / 手数
```

**用上面的例子（H=4416，L=4368）：**
```text
Buy Limit  4373     SL 4358     TP 4385     手数 0.02
Sell Limit 4411     SL 4426     TP 4399     手数 0.02
```

挂单纪律：
- 中间区 **不要** 挂限价（例如今天 4380–4404 禁止）
- **先成交哪边，就撤掉另一边**（防趋势日两边都挨打）
- 第一笔止损后：另一边 A 限价立刻撤
  - 若 **没破盒子** → 当天停
  - 若 **M15 已收盘破盒子** → 改做策略 B，不再挂 A
- 趋势日 / ADX>28 / 价格离开盒子 1.5×RANGE → **A 的两张限价立刻全撤**，改看 B
- 01:00 还没成交的限价 → 撤掉

### 备做法：等 RSI 再市价（可选）

只有不想提前挂单、想多看一眼时才用：
- 下沿 + M15 RSI<35 + 收阳 → 市价买
- 上沿 + M15 RSI>65 + 收阴 → 市价卖

少做、更慢，不是默认。

## 5. SL / TP / 手数（按你能扛 $10–20 来）

| 项目 | 填什么 |
|------|--------|
| SL | **$15**（可 12–18） |
| TP | **$12**（约 0.8R，高胜率默认）。想放大单笔再改回 $20–25 |
| 手数 | **0.02**（SL $15 时单笔约 $30） |
| 时间止损 | **90 分钟** 完全没动（浮盈从未超过 +$5）→ 平 |
| 最长 | **01:45 必须平**，睡着不留单 |
| 浮亏 | 允许抖到接近 SL；**不要** $5 就砍 |
| 保本 | 浮盈到 **+$8** 后，SL 移到入场价 |
| 冷却 | 两笔之间隔 **30 分钟** |

**手数为什么变小：** 止损从 $3 放到 $15，同样亏 $25，手数大约从 0.08 降到 **0.02**。  
账户亏的还是约 $25，只是价格可以多抖十几刀。

## 7. 策略 B：单边（突破回踩）

用来抓住「今天不震荡、一边倒」的行情。  
**不追第一波直拉**，等回踩再进。

### 何时从 A 切到 B

任一成立，A 全撤，只做 B：

- **M15 收盘** 高于 ASIA_H（向上突破）
- **M15 收盘** 低于 ASIA_L（向下突破）
- ADX(14) **> 28**，且 +DI / −DI 方向一致

影线刺破不算，必须收盘在盒子外。

### 怎么挂（同样限价）

**向上突破（只做多，禁止再空）**
```text
Buy Limit = ASIA_H（回踩原天花板，变支撑）
SL = 入场 - $15
TP = 入场 + $12
手数 0.02
```

**向下突破（只做空，禁止再多）**
```text
Sell Limit = ASIA_L（回踩原地板，变压力）
SL = 入场 + $15
TP = 入场 - $12
手数 0.02
```

**用今天盒子举例（H=4416）：**  
若 M15 **收盘站上 4416**，不要在 4414 追多，挂：

```text
Buy Limit  4416     SL 4401     TP 4428     手数 0.02
```

回踩不到 4416 就不成交，不算错过；追着大阳买才算乱做。

### B 的纪律

- B **每天最多 1 笔**
- 没回踩、限价不成交 → 空仓，不算错过
- A 已经止损、又切 B 再亏 → **当天停**（连亏 2 笔）
- 01:00 未成交的 B 限价撤掉
