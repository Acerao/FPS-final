# 大熊式画线（H8 压力 / 支撑 / 突破）

来源：抖音号 **大熊讲黄金**（39515581172），黄金科普账号。  
两条指定视频网页需要登录，拿不到完整口播；**以你发的 8 小时现货黄金图为准**，那就是他常用的画法。

这套是 **大周期结构**，不是日内刮单。  
评估账户用法：H8 定方向，**M15 亚盘盒子只做同方向的 B 回踩**。不要在 H8 通道里追第一波。

账号简介写明「分析仅作科普，不构成推荐」。下面只学画线和破位规则，不复制他的仓位。

## 图上他画了什么

你那张 `XAUUSD 8小时` 上只有三类线，先认全：

| 图上的东西 | 名字 | 作用 |
|------------|------|------|
| 上面那根往右下倾斜的线 | **下降压力线**（连接更低的高点） | 空头天花板。没站上去，反弹到线就视为压力 |
| 下面那根同样往右下倾斜的线 | **下降支撑线 / 通道下轨** | 空头地板。没跌破，回踩到线就视为支撑 |
| 两根一起 | **下降通道 / 收敛楔形** | 价格被夹在里面 = 震荡向下或挤压，等突破 |
| 底部那块蓝色横框 | **水平需求区 / 支撑箱** | 多次止跌的区域，不是一根精确价 |
| MA52 等均线 | **动态压力/支撑** | 图上约 4551，价格在均线下方 = 中期仍受压 |
| 底下 MACD 柱子缩到 0 轴附近 | **动能挤干** | 通道收窄 + MACD 接近 0 = 马上要选方向，不要在里面追 |

他不是把图画满。日常最多这几根。

## 怎么画（跟他一样，三步）

打开 **现货黄金 8 小时**（不要用 1 分钟画大结构）。

### 1. 压力线（上轨）

1. 找到最近两三个 **明显波段高点**（实体高点优先，影线可擦边）
2. 高点一个比一个低 → 连成向右下的直线，向右延长
3. 至少被点到 **2 次** 才算线；第 3 次再碰仍压住，这条线才「真」

这就是 **压力位**：价格涨到线附近，默认先当成「卖压」，不是无脑追多。

### 2. 支撑线（下轨）

1. 找最近两三个 **明显波段低点**
2. 低点一个比一个低 → 连成向右下的直线（常和上轨大致平行，形成通道）
3. 同样要 2 次以上触及

这就是通道里的 **支撑位**。

### 3. 水平箱（蓝框那种）

斜线管趋势，**横框管关键防守**：

- 同一带价格 **反复止跌 ≥2 次** → 画一个矩形，不要画成一根细线
- 框的上下沿用 **实体重叠区**，不要用一次长影线的极端价
- 整数关口（4400、4450）如果正好在框里，一起标

斜线 + 横框叠在一起，比单根线可靠。

均线（MA50/52）当第三层：价格在均线下方，向上打压力线更容易失败；站上均线后再破压力，突破更真。

## 怎么用：未破 vs 突破

### 还在通道里（没破）

- 上轨附近：**不做追多**。冲刺版直接空仓等破。
- 下轨或蓝框附近：只能当「可能止跌」，要用 **M15 确认K** 才考虑，而且评估期更推荐等破。
- MACD 贴 0、通道收窄：**更不要做**，这是他图里的「挤完再选边」。

对应你的软件：这时多半是盒子 A 的震荡日。原版可以挂 A；**冲刺版本来就不做 A，正好。**

### 什么叫有效突破（一定要收盘）

影线刺破不算。按 8 小时：

```text
向上破压力：H8 收盘站上下降压力线
            最好再站上蓝框上沿 / 前高
向下破支撑：H8 收盘跌破蓝框下沿，或跌破下降支撑线
```

假突破：盘中刺穿，收盘又回到通道里 → 当没破，原线还在。

### 破了以后怎么做（和你的盒子 B 是同一件事）

**压力变支撑 / 支撑变压力**，这是他这套里最值钱的一句：

1. H8 收盘向上破了下降压力线
2. **不要追第一根大阳**
3. 等价格 **回踩那根旧压力线**（现在变成支撑）
4. M15 出阳吞噬或更高低点
5. 按你现在的 B：限价回踩、SL $15、冲刺 TP $18

向下破蓝框则反过来：回抽箱沿做空。

亚盘盒子在这里的角色：  
**ASIA_H / ASIA_L 是当天的小压力/小支撑；H8 通道是几天的大压力/大支撑。**  
只做「大方向和小盒子突破方向一致」的那一笔。

## 接到你现在的三种模式

| 软件模式 | 画线怎么用 |
|----------|------------|
| `asia_box` | H8 还在通道里 → 可以做 A；H8 已破上轨 → 撤 A，只做向上的 B |
| `asia_box_hwr` | 同上，且 M15 必须确认K |
| `asia_box_sprint` | **H8 没破就空仓**；只做「H8 破压力 + 盒子向上破 + 回踩」这一类 |

每天 14:30 锁完盒子后加两句自问：

```text
H8 现在：通道内 / 已破上轨 / 已破下轨 / 蓝框还在
今天盒子只许做：多 / 空 / 空仓
```

H8 在通道内、盒子也没破 → 冲刺版空仓是正确的。  
H8 已破上轨、M15 收盘破 ASIA_H → 才是他那种「突破位」的做多。

## 不要从这套里学的

- 不要在 8 小时图上用超短止损 $2–4（那根通道一抖就是几十美元）
- 不要把斜线画成 10 根，图会废
- 不要把一次影线当突破
- 不要把科普号的点位当喊单去加仓、对冲、马丁

SL 仍按你的评估规则：**$15，手数用窗口里选的**。H8 只决定方向，不决定仓位。
