# 冲刺 $1k（评估期能加快、不能硬冲）

High Stakes **$10k** 若是 New 版，Phase1 目标就是 **10% = $1,000**。  
官方日损 **5% = $500（打到即淘汰）**，总亏 **10% = $1,000**。  
至少 **3 个盈利日**，每天净利 ≥ **$50**。

网上能搜到、又和评估规则兼容的，其实就三条，没有第四条捷径：

1. **手数按风险算，提到 0.5%–1%**（不是马丁）
2. **只做顺势回踩，不做盒子里逆势刮**（你两年回测里赚钱的是 B，不是 A）
3. **伦敦扫亚盘高低点后等确认**（就是现在的 B + 确认K）

搜索里常见的「几天翻倍 / 对冲 10 倍 / 百倍」全部会打穿日损，不做。

## 软件怎么用

策略选 **`asia_box_sprint`**，手数选 **0.05**（切到冲刺会自动从 0.02 提到 0.05）。

| 项目 | 冲刺版 |
|------|--------|
| 做什么 | **只做 B**（破盒回踩 + M15 确认K） |
| 手数 | **0.05**（可改 0.03 / 0.07） |
| SL | $15 → 单笔约 **$75** |
| TP | $18 → 单笔约 **$90** |
| 两连亏 | 约 **$150** |
| 个人日损 | 放到 **−$200**（仍远低于官方 −$500） |
| 每天 | 最多 2 笔，01:45 全平 |

界面手数下拉：`0.02 / 0.03 / 0.05 / 0.07`。提醒文案会写出「亏约 $xx / 盈约 $xx」。

## 为什么 0.02 到不了短期 $1k

0.02 手、TP $10–12，赢一笔大约 **$20–24**。  
就算天天打满，也要几十个交易日。两年粗回测里 2024+2025 合计只有一两百到四百。

0.05 手、TP $18：赢一笔约 **$90**，亏一笔约 **$75**。  
理论上 **12–20 个交易日** 能摸到 $1k（要几乎每天有 B 且执行不走样）。  
这是「加快」，不是保证。2024 这种年份冲刺也会慢。

## 手数对照（SL $15）

| 手数 | 单笔风险 | 两连亏 | 适合 |
|------|----------|--------|------|
| 0.02 | $30 | $60 | 稳过评估，慢 |
| 0.03 | $45 | $90 | 仍能守你原来的 −$100 |
| **0.05** | **$75** | **$150** | **冲刺默认** |
| 0.07 | $105 | $210 | 上限，再大就接近乱来 |

不要上 0.10+：一笔 $150，两笔就接近官方日损一半，评估期不值得。

## 网上别的策略结论

| 来源/类型 | 短期 $1k？ | 采用 |
|-----------|------------|------|
| Prop 通行：每笔 0.5%–1% 风险 | 几周，不是几天 | **采用**（0.05 手 ≈ 0.75%） |
| 伦敦扫 Asia high/low 再回踩 | 和盒子 B 相同 | **已在冲刺版** |
| YouTube 1:3 SMC | 单数太少，评估期偏慢 | 只借确认，不借 1:3 |
| 趋势线吞噬 | 可当确认K | 已在高胜率/冲刺 |
| 对冲网格 / 马丁 / 无硬止损 | 可能几天也可能归零 | **禁止** |

## 冲刺纪律

- 没破盒 → 空仓（不要手痒做 A）
- 破了追第一波 → 不算冲刺，是送日损
- 连亏 2 或当天 −$200 → 停
- 新闻前后 30 分钟 → 停
- 赚到 **+$1,000** 或 **+$800 且不想再赌** → 收工，不要再加大手
