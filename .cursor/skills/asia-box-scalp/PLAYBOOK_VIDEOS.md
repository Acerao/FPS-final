## 1. 币圈避雷针：截取 + 顺势 + 结构

**标题在说什么**  
不是「亏了翻倍」，是三件事叠在一起：

1. **截取**：不吃整段行情，只切一段（突破后的一段、回踩后的一段）
2. **顺势**：大方向对了才做，不在中间区猜顶底
3. **结构**：高低点、突破、回踩，不是纯指标

500U→11000U 是 **小资金高杠杆合约** 的结果展示，评估账户复制不了那个倍数。

**能抄**

- 和现有 **策略 B** 一致：破了再回踩，不追第一波
- 「截取」对应我们的短 TP（现在 TP $12）：评估期本来就不该扛到隔夜吃整段
- 结构确认可以加在 B 上：M15 收盘破盒后，再等一根反向结构（见文末「B 可选确认」）

**不能抄**

- 按 500U 那种仓位去滚 $10k
- 把「截取」理解成无止损刮头皮

## 2. 51 百倍：1000 → 100000

评论里已经把风险写清楚了：

- 3.2 万翻到 7 万那笔空单，**最大浮亏约账户 25%**

**能抄**：无。

## 3. 正道量化：现货黄金对冲

评论原话：「这算什么对冲，不就是上下挂突破单，突破空，突破多。」

市面同款 EA 通常是：

- 盒子/区间上下各挂
- 震荡里两边刮差价
- 单边时另一边锁仓，再网格加层
- 宣传「两个月 10 倍」

这和你喜欢的「跌了加、弹了全清」外表像，数学完全不同：

- 对冲 **不减风险**，只是把亏损藏成双边手续费 + 单边净敞口
- 黄金单边 $40–80 很常见，锁仓后浮亏不释放，日损照样打满
- The5ers 评估要看 **净值回撤**，锁仓不能让日损 magically 消失
- 你 **01:45 必须平**，对冲仓隔夜/跨数据更危险

**能抄**：无（连等距网格都已经证明：有硬止损则 PF 为负，无限层则浮亏上千到上万）。  
**不能抄**：双向挂单、锁仓、加层翻倍。

程序里的 `scale_grid` 已经是这类想法的 **安全阉割版**（等量、最多 3 层、硬止损）。评估期不要再往「对冲」加功能。

**能抄（作为 B 的可选过滤器）**

- 止盈：评估期默认仍 **TP $12（约 0.8R）**；若某天结构很干净、想试 1.5R，单笔风险仍锁 $25，手数不要加大

「每月 20 万」是结果包装，当故事看。规则本身是普通价格行为，和盒子 B 兼容。

**不能抄**：按月固定金额倒推手数。

## 5. YouTube：流动性 + 市场结构（最值得学）

口播规则（机械，不是马丁）：

```text
日线 / H4 定方向（结构没破就不要反着做）
标出真正相关的供需，而不是图上所有框
等价格扫流动性（前高/前低/供需区第一次拒绝）

限价回踩到供需或 FVG
止损在扫单影线外
止盈机械 1:3
持有到 SL 或 TP：不做保本、不分批
```

Prop 风控（作者自己的口径）：

- Phase1 **每笔 2%**
- 验证盘 / 实盘 **1%**
- 英国凌晨不做到亚盘（他 3:00 有信号也不做）

映射到你的账户：

| 他的规则 | 你该用的版本 |
|----------|----------------|
| Phase1 风险 2% | **不要 2%**。2% = $200，两笔就碰官方日暂停。继续 **约 0.25%（0.02 手 × SL $15 ≈ $30）** |
| 机械 1:3 | 评估期默认仍 **0.8R（TP $12）** 保过关；通过后再考虑 1.5R–3R |
| 不做亚盘凌晨 | 你 **08:00–14:30 只画盒子**，真正下单 15:00 后，已经避开亚盘噪音 |

**能抄**：日线方向、扫盒子流动性、M15 结构确认、单笔硬 SL。  
**不能抄**：为了 1:3 把止损收到 $3，或把手数加到 2%。

作者明确说这套 **不是翻倍策略**。和「跌了加仓」不是一类。

## 评估期最终怎么做

**主策略不变：亚盘盒子 A/B。**

从视频里只加三句，写进执行，不改软件自动下单：

1. **B 不要看见破盒就追。** 继续挂回踩限价。有空再等 M15 吞噬 / 结构翻转，没有确认就让限价自己成交或不成交。
2. **方向服从更高周期。** H1 连阴时不要在盒子上沿死扛空单；那是百倍视频里的「抗」，不是盒子 A。
3. **仓位永远按美元风险算**，不按「再翻一倍」算。

```text
允许：亚盘盒子 A/B、限价、SL $15 / TP $12、0.02 手
允许：B 加一层结构确认（吞噬 / CHoCH）
备选：等距网格最多 3 层、等手数、硬止损（震荡日）
禁止：翻倍马丁、无限层、无硬 SL、多空对冲锁仓、百倍仓位
禁止：为了视频里的 10 倍 / 100 倍去改日损线
```

过了 Phase1 再谈 1:3 和稍大目标。评估期目标是 **活着过线**，不是复制任何一条视频的资金曲线。
