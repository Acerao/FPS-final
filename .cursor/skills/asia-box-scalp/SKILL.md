# 亚盘盒子超短（Asia Box Scalp）

评估期防守版。先读 [PLAYBOOK.md](PLAYBOOK.md)，按清单执行。

## 何时用

- 用户给了 `ASIA_H` / `ASIA_L` 或今日黄金图
- 问现在能不能买/卖、SL/TP/手数
- 说「按盒子做」「跑一下黄金超短」

## 执行顺序

1. 用北京时间判断窗口：S2 `15:00-17:00` 或 S3 `21:00-22:30`。窗外不做。
2. 盒子未锁（未到 14:30）→ 只标记，不按 A 下单。
3. 计算三区（见 PLAYBOOK）。价格在中间区 → 明确说「空仓」。
4. 趋势日（H1 连 3 大根 或 ADX>28）→ 禁止 A 反转。
5. 给出：做多/做空/空仓 + 入场区 + SL + TP + 手数。
6. 提醒硬刹车：无 SL 不下单、连亏 2 停、日损 -$100 停、22:30 全平。

## 禁止

- 不代替用户下单
- 不在中间区找「差不多能做」的理由
- 不把本策略说成某位华尔街大佬的原版秘籍
