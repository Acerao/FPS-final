# 《同一班车，两个站点》6 集剧本

**类型：** 新海诚式青春 / 超能力 / 校园感情  
**体量：** 6 集 × 约 80 秒  
**画风：** 2D，新海诚（雨、电车、窗光、城市远景、重复月台）；即梦不要生成中文  

---

## 一句话

同一班电车，他能开到「今天的站」，也能开到「记忆里的站」。  
他总去有她的旧站台；她在今天的站等他——直到记忆站空了。

---

## 能力规则（全季写死）

| 项目 | 规则 |
|---|---|
| 触发 | 必须坐上 **同一条线路、同一班次感** 的电车（校园线/通勤线） |
| 选择 | 到站前闭眼，选 **「今天」** 或 **「记忆」** |
| 记忆站 | 只能开到 **自己真实去过、且情绪记得住** 的站台场景 |
| 限制 | 每天最多 **2 次** 进记忆站；出站后回到 **现实时间**（不时间旅行改历史） |
| 表现 | 车窗景切换：同车厢、不同站台光/天气/人流；门开瞬间光尘一闪 |
| 禁止 | 无失忆、无残影、无练功、无末日打怪 |

**观众先以为：** 他能「回去见她」。  
**实际：** 他去的是 **记忆里的站**，不是真把她召回来；她活在 **今天的站**。

---

## 人物

**阿名**  
大学生，嘴硬，习惯用「回旧站」逃避今天的尴尬。  
服装：军绿棒球夹克 + 灰 T + 黑牛仔裤 + 白鞋。

**陈夏**  
黑长直中分，米色宽松卫衣 + 浅蓝牛仔裤 + 白鞋。  
同班熟同学；会等，也会不等。

**大刘**  
室友；第 1 集可吐槽「你又坐过站」。

---

## 6 集总览

| 集 | 标题 | 核心 | 钩子 |
|---|---|---|---|
| 1 | 过站 | 第一次亮能力：本该到「今天站」，他开进「记忆站」 | 陈夏：`{你又坐过了？}` |
| 2 | 旧月台 | 他反复去「有她的旧站」；现实里她在今天等 | `{我今天在 3 号口。}` |
| 3 | 错站 | 他以为在记忆里遇见她；出站发现是幻觉式重逢 | `{车上的我，不是现在的我。}` |
| 4 | 今天 | 她约他必须下「今天站」；他第一次坚持不下记忆 | `{别用回忆来见我。}` |
| 5 | 空站 | 记忆站空了；他疯找旧月台 | `{不是站没了。是你不想保了。}` |
| 6 | 同站 | 两人上同一班车，都选今天；第一次同站下车 | `{这班，不下回忆。}` |

# 第 1 集《过站》

**目标：** 电车空镜抓眼；能力 10 秒内懂；挂上陈夏。

### 剧情

傍晚。校园站。阿名跑着赶车，差点误点。  
上车。车厢拥挤，窗外星城灯火（新海诚）。

报站：「下一站，明德大学。」  
他本该下车。手机震：陈夏 `{我在 3 号口等你。}`  

他犹豫，闭眼——车窗景 **从今日黄昏切到去年初夏**（同一站名，光不同，人流不同）。  
门开。他下到 **记忆里的校园站**：她曾在这里说过 `{下次一起坐到终点。}`

他站在空月台，愣住。再眨眼，回到现实车厢——车已过站。

现实站台。陈夏看着晚点的他：  
陈夏：`{你又坐过了？}`  
阿名：`{……车门夹人。}`  
陈夏：`{你眼睛红红的。}`  
阿名：`{风大。}`

结尾：他回望轨道，字幕（剪映）：**同一班车，两个站点。**

### 关键对白
```
陈夏（消息）：{我在 3 号口等你。}
陈夏：{你又坐过了？}
阿名：{……车门夹人。}
陈夏：{你眼睛红红的。}
```

# 第 2 集《旧月台》

**目标：** 爽用能力；埋「她在今天等」。

### 剧情

蒙太奇：他连着两天进记忆站——  
旧天桥口、旧奶茶店旁的小站、雨天两人躲过的屋檐站。

记忆里「陈夏」只会重复 **过去说过的话**（不是真交互 NPC，是记忆回放感）。  
他越听越安心，也越不像活在今天。

现实。陈夏发消息：`{我今天在 3 号口。}` `{别过站。}`  
他回：`{马上。}` —— 却又进了记忆站。

出站后赶到 3 号口，她已经走了。只留一张便利贴在柱子上（剪映字）：  
`{你总去你想去的站。}`

钩子：阿名捏着便利贴，车厢广播：「本线末班车……」

### 关键对白
```
陈夏（消息）：{我今天在 3 号口。别过站。}
阿名（消息）：{马上。}
便利贴：{你总去你想去的站。}
```

---

# 第 3 集《错站》

**目标：** 假重逢；说清「记忆站不是她」。

### 剧情

他故意进一个「最像会遇见她」的记忆站。  
门开，记忆里的陈夏朝他笑：`{你来啦。}`  
他冲过去：`{我有话跟你说——}`  

画面微抖、光尘散——她像 **胶带拉起的重影**，话卡在旧台词：`{下次一起坐到终点。}`  

他伸手，抓空。  
出站。现实天桥。真正的陈夏站在对面，表情冷静。

陈夏：`{车上的我，不是现在的我。}`  
阿名：`{你怎么知道？}`  
陈夏：`{因为现在的我，不会在旧站等你了。}`  

雨开始下。两人隔着车流。  
钩子：她撑伞先走：`{你要见我，来今天。}`

### 关键对白
```
记忆陈夏：{你来啦。} / {下次一起坐到终点。}
陈夏：{车上的我，不是现在的我。}
陈夏：{现在的我，不会在旧站等你了。}
陈夏：{你要见我，来今天。}
```

# 第 4 集《今天》

**目标：** 冲突；约定；他第一次不下记忆。

### 剧情

白天教室。她把两张纸条拍他桌上：  
一张写「今天站」；一张写「记忆站」。

陈夏：`{放学同一班车。}` `{你选。}`  
阿名：`{这算考试？}`  
陈夏：`{算。}` `{别用回忆来见我。}`

放学。上车。报站将近。  
他手心出汗，闭眼——车窗外 **几乎切到记忆光**——他又睁开，强迫自己选今天。

门开。今天站。她在 3 号口。  
陈夏：`{……你下来了。}`  
阿名：`{废话。}`（嘴硬）  
陈夏笑一下：`{那就走吧。今天的路。}`

钩子：他回头看车门关上，像戒断。手机备忘：今天还剩 1 次记忆站——他没用不舒服。

### 关键对白
```
陈夏：{放学同一班车。你选。}
陈夏：{别用回忆来见我。}
陈夏：{……你下来了。}
阿名：{废话。}
陈夏：{那就走吧。今天的路。}
```

# 第 5 集《空站》

**目标：** 「找不到她」——记忆站空了。

### 剧情

吵架后（或冷战一天）。他想用记忆站「找安慰」。  
连开两次：旧月台、雨屋檐站——**全空**。没有她的身影，没有旧台词。

他慌了，以为能力坏了。狂坐车、换车、再进记忆——还是空。  
站在空轨道风里喊：`{陈夏！}`

电话。  
阿名：`{你去哪了？记忆里没有你。}`  
陈夏：`{不是站没了。}` `{是你不想保了。}`  
阿名：`{什么意思？}`  
陈夏：`{你开始想今天了。}` `{旧站就会空。}`  

挂断。  
钩子：车窗映出他的脸；远处今天站的灯还亮着。

### 关键对白
```
阿名：{你去哪了？记忆里没有你。}
陈夏：{不是站没了。是你不想保了。}
陈夏：{你开始想今天了。旧站就会空。}
```

# 第 6 集《同站》

**目标：** 终局；同一班车；都选今天；在一起。

### 剧情

傍晚。两人约在上车点碰面——**先见面，再上车**（不再各上各的）。  
阿名：`{今天……不下回忆。}`  
陈夏：`{嗯。}` `{我也不当回忆。}`

上车。车厢灯、窗外雨丝、城市远景。  
报站。他握着吊环，闭眼又睁开——**不切记忆**。  
门开。两人一起下「今天站」。

出站口。她停步：`{你还想回去看看空站吗？}`  
阿名：`{空就空吧。}` `{人在这。}`  
陈夏：`{……行。}` `{那就一起坐到——}`  
阿名：`{不用到终点。}` `{到你想去的下一站就行。}`

终镜：两人走在今天的出站通道；身后一班车开走，车窗里 **没有切到旧光**。  
字幕（剪映）：**同一班车。只下一站：今天。**

### 关键对白
```
阿名：{今天……不下回忆。}
陈夏：{我也不当回忆。}
陈夏：{你还想回去看看空站吗？}
阿名：{空就空吧。人在这。}
阿名：{到你想去的下一站就行。}
```

## 情绪曲线

```
发现能力(1) → 沉溺旧站(2) → 假重逢拆穿(3) → 选今天(4) → 空站恐慌(5) → 同站下车(6)
```

---

## 新海诚拍摄要点

1. **电车窗：** 每集至少一组「窗景切换」——同构图，不同天气/季节光。  
2. **月台：** 重复机位（柱子、3 号口、轨道尽头）区分「今天 / 记忆」。  
3. **能力特效：** 只要门开光尘 + 窗外一切；不要虫洞、不要传送。  
4. **记忆陈夏：** 略「不对劲」（口型重复、光影偏暖、不回应新话题）。  
5. **禁止：** 热鸡蛋式练功、末日兑现、宿舍刷手机收尾、能力说明书旁白。
