# 《跳过无聊》6 集剧本

**类型：** 新海诚式青春 / 超能力 / 校园感情  
**体量：** 6 集 × 约 80 秒（16 条 × 5 秒）  
**画风：** 2D，新海诚光影；即梦不要生成中文，字幕剪映加  

---

## 一句话

他能跳过人生里一切「无聊的十分钟」——  
却发现，和她有关的时间，一旦跳过，就再也补不回来。

---

## 能力规则（全季写死）

| 项目 | 规则 |
|---|---|
| 次数 | 每天最多 **3 次** |
| 单次 | 跳过最多 **10 分钟** |
| 可跳 | 排队、通勤、等电梯、等红灯、无意义等待 |
| 不可跳 | **和陈夏同框相处的时间**（他以为能跳，其实跳了她那边照样过） |
| 副作用 | **无**身体惩罚；代价在关系里：她会感到「你突然不在了」 |
| 表现 | 周围人群/场景 **抽帧快进**，他像被剪掉一截；光、影子、雨丝会跳一下 |

**观众先以为：** 赖床神技、永不迟到。  
**实际：** 跳过的是时间，跳不过的是 **在场**。

---

## 人物

**阿名（男主）**  
20 岁，大学生。嘴硬、怕麻烦、把「省时间」当优点。  
服装：军绿棒球夹克 + 灰 T + 黑牛仔裤 + 白鞋。

**陈夏（女主）**  
黑长直中分。米色宽松卫衣 + 浅蓝牛仔裤 + 白鞋。  
同班熟同学，不圣母，会直接说。

**大刘（室友）**  
第 1 集喜剧位；后面可偶尔出场。

# 第 1 集《再睡会》

**目标：** 3 秒懂迟到；5 秒笑；10 秒能力抓眼；结尾挂上陈夏。

### 剧情

宿舍闹钟爆响。阿名掀被看表，脸色发白。  
大刘蒙着被子：`{别急，再睡会。}`  
阿名：`{早八！点名！}`  
大刘：`{那你昨晚别刷手机。}`

阿名冲出宿舍，跑向校道。人太多、红灯太长。  
他站在人潮里，闭眼。

**能力发动：** 校道人群抽帧快进，光一跳——他已在教学楼门口，铃刚响。

同学侧目。他理理衣领，装没事：`{……到了。}`

教室门口遇陈夏。她看了眼表：`{你今天……}`  
阿名：`{抄近路。}`  
陈夏：`{你上次也这么说。}`  
阿名：`{……顺路。}`

陈夏看他一眼，轻声：`{你又像凭空出现。}`  

黑场。字幕（剪映）：**跳过无聊 · 01**

### 本集暴露
- 他能「跳过」通勤/等待  
- 陈夏隐约觉得他「出现方式不对」  
- **不解释** 次数、规则细节

### 关键对白
```
大刘：{别急，再睡会。}
阿名：{早八！点名！}
阿名：{抄近路。}
陈夏：{你又像凭空出现。}
```

# 第 2 集《顺路》

**目标：** 能力很爽；埋「她会察觉缺席」。

### 剧情

蒙太奇：食堂排队 → 他跳过 → 拿餐走人。  
图书馆等电梯 → 跳过 → 门开他已在里。  
天桥等红灯 → 跳过 → 绿灯人群里他已在对面。

自习室。陈夏抬头，阿名坐对面，资料已摊开。  
陈夏：`{你什么时候来的？}`  
阿名：`{刚到。顺路。}`  
陈夏：`{你今天顺路次数有点多。}`

两人一起找资料。中间有段安静——他觉得「等她翻页好无聊」，下意识想跳。

**他跳了 10 秒。**  
她那边：他像短暂「卡死/空白」，再抬头人还在，但眼神对不上。

陈夏皱眉：`{你人呢？刚才还在。}`  
阿名：`{我一直在啊。}`  
陈夏：`{……算了。}`

结尾：他看手机备忘录，写着「今天还剩 1 次」。  
窗外黄昏。陈夏收拾书包：`{下次别突然消失。}`  
阿名：`{我哪消失了。}`

钩子：她走后，他看着空座位，第一次不确定。

### 关键对白
```
陈夏：{你什么时候来的？}
阿名：{刚到。顺路。}
陈夏：{你人呢？刚才还在。}
陈夏：{下次别突然消失。}
```

# 第 3 集《红灯》

**目标：** 第一次在她面前「跳等灯」→ 冲突升级。

### 剧情

放学。两人并肩走。红灯。人很多。  
阿名下意识看表，不耐烦。  
陈夏：`{等一会就好。}`  
阿名（嘀咕）：`{就这最烦。}`

他发动能力——跳过红灯。  
**她这边：** 灯还没变，身边人空了一下，他已在马路对面招手。

陈夏愣住，过马路走到他面前。  
陈夏：`{你刚才怎么过去的？}`  
阿名：`{绿灯了啊。}`  
陈夏：`{我这边还是红的。}`

沉默。雨丝开始下（新海诚）。  
陈夏：`{别用那种方式离开。}`  
阿名：`{什么方式？}`  
陈夏：`{像你从来没好好等过。}`

她先走。他站在斑马线旁，绿灯亮了，他第一次 **没有跳**，跟着走——但她已经拐弯。

钩子：他低头，嘀咕：`{……那就别让我等。}`（嘴硬）

### 关键对白
```
陈夏：{等一会就好。}
陈夏：{你刚才怎么过去的？}
阿名：{绿灯了啊。}
陈夏：{别用那种方式离开。}
```

# 第 4 集《缺席》

**目标：** 揭规则情感版；吵架；不讲说明书脸。

### 剧情

走廊。陈夏拦他。  
陈夏：`{我们谈谈。}`  
阿名：`{谈什么。}`  
陈夏：`{你是不是有时候……会「跳走」？}`

他想否：`{你想多了。}`  
她盯着他：`{图书馆那次。红灯那次。还有你总「凭空出现」。}`

僵持。他认：`{我能跳过一些无聊的时间。}` `{排队、等灯、通勤。}`  
陈夏：`{那和我在一起的时候呢？}`  
阿名：`{……那不算无聊。}`（嘴硬破功，又补）`{偶尔也会。}`

陈夏笑了一下，不好看。  
陈夏：`{你跳过的，刚好都是我。}`  
阿名：`{我没有。}`  
陈夏：`{你有。}` `{你人在，心不在。}` `{能力只是让你更快而已。}`

她把资料还给他：`{以后见面，别跳。}`  
阿名：`{那很浪费。}`  
陈夏：`{那就别见。}`

钩子：他站在空走廊，窗外雨。他第一次 **没用掉今天剩余次数**。

### 关键对白
```
陈夏：{你是不是有时候……会「跳走」？}
阿名：{我能跳过一些无聊的时间。}
陈夏：{你跳过的，刚好都是我。}
陈夏：{以后见面，别跳。}
阿名：{那很浪费。}
陈夏：{那就别见。}
```

# 第 5 集《找遍一天》

**目标：** 想见她，却越跳越空（对应你要的「找不到」）。

### 剧情

阿名一天没用能力找她：教室、图书馆、奶茶店、天桥——**都空**。  
他烦了，开始跳：跳过走路、跳过等电梯、跳过雨里的等待——**像在快进人生找人**。

每个地方都像「她刚走」：杯子还温、椅子拉开。  
不是闹鬼，是 **她在正常移动，他在跳时间**，永远对不上。

天桥空镜。他用完第三次。  
电话接通。  
阿名：`{你在哪？}`  
陈夏：`{别找了。}`  
阿名：`{我找遍了。}`  
陈夏：`{你找的是捷径。}` `{我不等「突然出现」的人。}`

挂断。  
他站在雨里，第一次觉得 **能力一点用没有**。

钩子：手机亮，一条消息（剪映字）：`{如果你还想找——别跳过来。}`

### 关键对白
```
阿名：{你在哪？}
陈夏：{别找了。}
阿名：{我找遍了。}
陈夏：{我不等「突然出现」的人。}
消息：{如果你还想找——别跳过来。}
```

# 第 6 集《不跳》

**目标：** 终局反转 = 不靠能力；走路 + 等完整段无聊；在一起。

### 剧情

阿名回消息：`{好。}`

他 **跑步** 去她说的地方（新便利店门口 / 新天桥下——**不是旧自习室**）。  
校道、雨、红灯——他站在红灯前，手指动了动，**没有跳**。  
完整等完。绿灯。继续跑。

她在便利店檐下躲雨，两杯热饮，一杯已经有点凉。  
陈夏：`{你传……你怎么来的？}`  
阿名（喘）：`{跑的。}` `{红灯也等了。}`  
陈夏：`{……傻不傻。}`  
阿名：`{挺无聊的。}` `{但我都在。}`

两人并排坐台阶。雨还在下。时间明明很「无聊」，他没有跳。

陈夏：`{下次早八还跳吗？}`  
阿名：`{跳。}` `{但见你——不跳。}`  
陈夏看他一眼，笑：`{行。}` `{那你今天欠我十分钟。}`  
阿名：`{那就陪你坐满。}`

终镜：便利店门口，雨，窗光；两人坐着，时钟走完一小段。  
字幕（剪映）：**有些时间，不能跳过。**

### 关键对白
```
阿名：{跑的。红灯也等了。}
阿名：{挺无聊的。但我都在。}
陈夏：{下次早八还跳吗？}
阿名：{跳。但见你——不跳。}
陈夏：{那你今天欠我十分钟。}
阿名：{那就陪你坐满。}
```

## 拍摄/即梦注意事项

1. **能力画面：** 人群抽帧、光跳一下、他位置/场景切换；不要虫洞、不要传送门。  
2. **第 2、3 集：** 重点拍「她视角的不对劲」——他空白、突然到对面。  
3. **第 5 集：** 空镜要多，新海诚：雨、天桥、空椅、余温。  
4. **第 6 集：** 红灯全段不跳，是全季最重要的「无聊」。  
5. **不要：** 宿舍看手机收尾、3:33、失忆、残影、能力说明书旁白。
